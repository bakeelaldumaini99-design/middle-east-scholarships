# مؤسسة الشرق الأوسط للمنح الدراسية

موقع تعريفي عربي بالكامل (RTL) لمؤسسة الشرق الأوسط للمنح الدراسية — منح دراسية لبرامج **البكالوريوس** و**برنامج اللغة الصينية** في أعرق الجامعات الصينية.

## أقسام الموقع

- 🏛️ **الجامعات الشريكة** — 8 جامعات صينية حكومية مرموقة مع المدينة والتصنيف وأبرز التخصصات
- 🎓 **برامج البكالوريوس** — 6 برامج (هندسة الحاسوب، إدارة الأعمال، الطب، الهندسة المدنية، اللغة الصينية، التجارة الدولية) مع المدة ولغة الدراسة والحقول
- 🇨🇳 **برنامج اللغة الصينية** — 3 مستويات (HSK 1-2، 3-4، 5-6) مع المدة والمميزات ومواعيد الالتحاق
- 📋 **خطوات التقديم** — 5 خطوات من تقديم الطلب حتى الفيزا والسفر
- 📞 **تواصل معنا** — معلومات الاتصال والروابط السريعة

## التقنيات المستخدمة

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 3.4 + نظام ثيم shadcn/ui
- React Router 7
- خطوط عربية: Cairo و Tajawal

## التشغيل محليًا

```bash
npm install
npm run dev      # خادم التطوير على http://localhost:3000
npm run build    # بناء الإنتاج إلى dist/
npm run preview  # معاينة نسخة الإنتاج
```

## هيكل المشروع

```
src/
├── data/content.ts        # كل نصوص وبيانات الموقع (جامعات، برامج، مستويات)
├── pages/Home.tsx         # تركيب الصفحة الرئيسية
├── sections/              # أقسام الموقع (Hero, Universities, Bachelor, ...)
├── components/ui/         # مكونات shadcn/ui المستخدمة (Button, Card, Badge)
├── hooks/                 # خطافات مساعدة
└── lib/utils.ts           # دالة cn لدمج الأصناف
```

> ملاحظة: لإضافة مكونات shadcn/ui إضافية استخدم: `npx shadcn@latest add <component>`
